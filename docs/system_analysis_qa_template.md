### Q1: このシステムは何をするものですか？（一行要約）
**A**: 2人のユーザーがブラウザ上でポーカーのドローポーカーでオンライン対戦できるWebアプリケーション

**詳細**:
- ビジネス目的: オンライン対戦ゲームの実装を通じて、WebSocket通信、ゲームロジック、AWSデプロイの実践経験を得る

  - ルーム作成・参加機能（6桁のランダムID）
  - カード配布（各プレイヤーに5枚ずつ）
  - カード交換（1-3回選択可能）
  - 役判定（10種類のポーカー役）
  - 勝敗判定・結果表示
  - 戦績管理（サーバー側でJSONファイルに保存）
- ターゲットユーザー: Webゲームを気軽に遊びたい人、ポーカーの基礎ルールを学びたい初心者
- 価値提案: シンプルな操作でポーカーを楽しめる、リアルタイム対戦が可能

## 🏗️ アーキテクチャ

### Q4: 全体アーキテクチャは？
**A**: クライアント・サーバー型のリアルタイム通信アプリケーション

**構成図**:
```
[ブラウザ（クライアント）]
    ↓ WebSocket (Socket.IO)
[Flask + SocketIO サーバー]
    ↓ メモリ管理
[ゲーム状態管理（GameRoom）]
    ↓ ファイルI/O
[JSONファイル（戦績データ）]
```

**詳細**:
- フロントエンド: HTML/CSS/JavaScript（Vanilla JS）、Socket.IO Client（CDN）
- バックエンド: Python 3.8+、Flask 2.2.5、Flask-SocketIO 5.3.5、eventlet（非同期処理）
- データベース: なし（ゲーム状態はメモリ管理、戦績はJSONファイル）
- インフラ: AWS EC2（Amazon Linux 2023）、Nginx（リバースプロキシ）、AWS ALB（Application Load Balancer）、AWS ACM（SSL証明書）
- 外部連携: GitHub（コード管理）、AWS SSM Session Manager（サーバー接続）

## 🗄️ データ設計

### Q16: 主要なデータモデルは？
**A**: 

**エンティティリスト**:
1. **GameRoom（ゲームルーム）**
   - `room_id`: 6桁のランダムID
   - `players`: プレイヤー情報（socket_idをキー）
   - `deck`: デッキオブジェクト
   - `phase`: ゲームフェーズ（waiting, dealing, draw_phase, result）
   - `max_exchanges`: 最大交換回数（1-3）
   - `current_exchange_round`: 現在の交換ラウンド（0ベース）

2. **Player（プレイヤー）**
   - `name`: プレイヤー名
   - `hand`: 手札（5枚のカード配列）
   - `ready`: 交換完了フラグ
   - `player_number`: プレイヤー番号（1 or 2）

3. **Card（カード）**
   - `suit`: スート（♠, ♥, ♦, ♣）
   - `value`: 数値（1-14、A=14）
   - `label`: 表示ラベル（A, 2-10, J, Q, K）

4. **HandResult（役判定結果）**
   - `hand_name`: 役名（英語）
   - `rank_value`: 役の強さ（数値）
   - `high_card`: タイブレーク用のハイカード

5. **PlayerStats（戦績）**
   - `totalGames`: 総対戦数
   - `wins`: 勝利数
   - `losses`: 敗北数
   - `draws`: 引き分け数
   - `hands`: 役の記録（役名をキー、出現回数を値）

**主要なリレーション**:
```
GameRoom (1) ←→ (2) Player
Player (1) ←→ (5) Card
Player (1) ←→ (N) PlayerStats（履歴）
```


**ロールバック手順**:
```
1. git logで過去のコミットを確認
2. git reset --hard <commit_hash>で過去の状態に戻す
3. systemdサービスを再起動
```

## 🔍 トラブルシューティング

### Q31: よくある問題と対処法は？
**A**: 

| 問題 | 原因 | 対処法 |
|------|------|--------|
| Socket.IO接続エラー | サーバーが起動していない | `sudo systemctl status poker-game`で確認、再起動 |
| カードが交換されない | クライアント側のインデックス不一致 | サーバー側でも手札をソート（`hand_sorter.py`） |
| 戦績が保存されない | ファイルパーミッションエラー | `sudo chown -R ec2-user:ec2-user backend/`で所有権変更 |
| 2ターン目の交換ボタンが無効 | イベントタイミングの問題 | `next_exchange_round`イベントで複数回`enableExchangeButtons()`を呼び出し |
