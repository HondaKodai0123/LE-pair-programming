## 📋 使い方

このテンプレートは以下の用途で使用します：

1. **新規プロジェクト参画時**: システム全体を把握するためのチェックリスト
2. **AI（Cursor/Claude）への説明**: ソースコードを読み込ませる前に概要を伝える
3. **ドキュメント作成**: 他のエンジニアへの引き継ぎ資料
4. **レビュー**: アーキテクチャ設計の妥当性確認
