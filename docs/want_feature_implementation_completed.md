## 📋 実装内容

### 実装した機能

1. **手札の自動並び替え**
   - カード配布時に自動的に並び替え
   - カード交換後に自動的に並び替え
   - ペアを左側に配置

   - ペア（2枚以上同じ数字）を検出
   - ペアを数字の大きい順にソート
   - 単独カードを数字の大きい順にソート
   - ペアを左側、単独カードを右側に配置

3. **カード選択の改善**
   - 並び替え後も選択状態を保持
   - カードに一意のIDを付与して追跡

## 🛠️ 実装した変更

### 1. `frontend/js/game.js` の変更

#### 追加した関数

- **`sortHand(cards)`**: 手札を自動的に並び替える関数
  - ペアと単独カードを分離
  - ペアを数字の大きい順にソート
  - 単独カードを数字の大きい順にソート
  - ペアを左側、単独カードを右側に配置

- **`getSelectedCardIndices()`**: 選択されたカードのインデックスを取得
  - カードIDからスートと値を抽出
  - 現在のplayerHandから該当するカードのインデックスを検索

#### 修正した関数

- **`createCardElement(card, index)`**: カード要素に一意のIDを追加
  - `cardId`を`${card.suit}-${card.value}-${index}`形式で生成
  - 選択状態を`selectedCardIds`配列で管理

- **`toggleCardSelection(cardElement, cardId)`**: カード選択のトグル
  - インデックスではなくカードIDで選択状態を管理
  - 並び替え後も選択状態を保持

#### 修正したイベントハンドラー

- **`cards_dealt`**: カード配布時に`sortHand()`を呼び出し
- **`cards_exchanged`**: カード交換後に`sortHand()`を呼び出し
- **`exchange-btn`**: カード交換ボタンで`getSelectedCardIndices()`を使用

#### 追加したグローバル変数

- **`selectedCardIds`**: 選択されたカードのIDを保存（並び替え対応）

## 🔧 技術的な詳細

### 並び替えアルゴリズム

1. **グループ化**: 同じ数字のカードをグループ化
2. **分類**: ペア（2枚以上）と単独カードに分類
3. **ソート**: 
   - ペア: ペアの種類（トリプル > ペア）→ 数字の大きい順 → スート順
   - 単独: 数字の大きい順 → スート順
4. **配置**: ペアを左側、単独カードを右側に配置

### カード選択の管理

- **カードID**: `${card.suit}-${card.value}-${index}`形式
- **選択状態**: `selectedCardIds`配列で管理
- **並び替え対応**: カードIDで選択状態を追跡
